# Archived original Game Boy experiment

The active feature on this branch is [in-game GBA nearby trading](../TradeLink/README.md).
Use its build, packaging and save-safety instructions. The current framework no
longer contains the old home overlay or standalone Host/Join screen.

This directory retains the earlier SameBoy original-GB engine and its tests for
reference. Those sources target original Pokemon Red/Blue and are separate from
gpSP Gen3 GBA serial emulation. The active workflow builds `TradeLink`, not the
archived GB UI. Earlier GB IPA builds should not be used to test GBA trading.
